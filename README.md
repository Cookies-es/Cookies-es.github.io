# TrainTracker

Многостраничное фитнес-приложение на HTML, CSS и Vanilla JavaScript.

## Запуск
1. Распакуйте папку TrainTracker.
2. Откройте `login.html` в браузере. Можно также запустить через локальный сервер (например, Live Server).
3. Зарегистрируйте демо-аккаунт. Данные сохраняются в localStorage браузера.

## Страницы
- login.html — регистрация и вход
- index.html — дашборд
- calculator.html — ориентировочный калькулятор КБЖУ
- workouts.html — конструктор и сохранение тренировок
- recipes.html — рецепты
- reviews.html — отзывы
- profile.html — профиль, экспорт и удаление локальных данных

## Важно
Это фронтенд-демо. Авторизация не защищена сервером, пароль хранится в localStorage и не подходит для реальных аккаунтов. Не используйте настоящий пароль. Калькулятор КБЖУ — ориентир, не медицинская рекомендация; для несовершеннолетних не предназначен для ограничения питания.
